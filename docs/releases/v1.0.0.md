# Release Notes — HHGR v1.0.0

**Released:** 2026-09-02
**License:** MIT

## Overview

HHGR (Hybrid Hierarchical Graph Retrieval) is an explainable, multilingual question-answering system for Indian legal documents. It combines a custom legal hierarchy parser, a four-signal hybrid retrieval engine, a multi-stage verification framework, and LLM-generated cited answers to deliver grounded, auditable legal responses.

## Features

- **Hybrid Hierarchical Graph Retrieval** — Fuses four complementary signals (lexical, citation, hierarchy, structural) over a legal knowledge graph with configurable weights (dense 0.40 / graph 0.35 / hierarchy 0.25).
- **Legal Hierarchy Parser** — Stack-based parser with 20+ numbering patterns that extracts Document → Chapter → Section → Clause trees, building Nested Set Indices for fast subtree queries.
- **Multi-Stage Verification Framework** — 12-component pipeline: evidence sufficiency, evidence relevance, citation entailment, verification badge (5-priority rules), confidence calibration, and structured audit traces.
- **Explainable Answers** — Every response includes source citations, a 6-step reasoning chain, counter-authority detection (overruled/superseded/repealed/void), and full retrieval provenance.
- **Full-Stack Application** — React 18 + TypeScript dashboard with Cytoscape KG visualization, React Flow hierarchy views, and Recharts confidence plots.
- **Production Infrastructure** — 6-service Docker Compose stack (FastAPI, React, Neo4j, Qdrant, Redis, nginx), Prometheus/Grafana monitoring, API key auth with per-IP rate limiting, and health probes.
- **Multilingual Support** — bge-m3, LaBSE, MuRIL, and IndicBERT embeddings for English + Indic language documents.

## Architecture

```
Legal PDF/DOCX/TXT → Ingestion (OCR, Lang) → Hierarchy Parser → Knowledge Graph
                                                                    │
Question → Query Analysis → HHGR Retrieval (4-signal fusion) ◄─────┘
                              │
                              ▼
                    Vector Store (Qdrant)
                              │
                              ▼
                    Verification Framework (sufficiency, relevance,
                    entailment, badge, calibration)
                              │
                              ▼
                    LLM Answer Generation (cited, explainable)
                              │
                              ▼
                    React Dashboard (Evidence, KG, Provenance)
```

## Benchmarks

- 50-question benchmark across 5 legal domains
- 5 retrieval systems compared: HHGR, dense, BM25, graph, naive RAG
- 6-arm ablation study
- Before/after parser-fix comparison documented

## Known Limitations

- Answer-related metrics (Answer Accuracy, Hallucination Rate, Faithfulness) reflect the **mock LLM**, not the production NVIDIA model's answer quality.
- The retrieval layer is validated against Indian Contract Act 1872 and the Indian Penal Code; other legal domains require corpus-specific evaluation.
- Live Neo4j persistence is available but the default deployment uses the in-memory graph.
